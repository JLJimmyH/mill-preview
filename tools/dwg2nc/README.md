# dwg2nc — 2D 板件工程圖（DWG）轉 NC 程式

丟一張板件的 DWG 進去，產出 Fanuc 加工中心的 NC 程式、刀具表 CSV、素材檔和一份報告，三個檔案拖進[銑床預演台](../../nc-preview/)就能看成品、跑檢查。

這是命令列工具，跑在你的電腦上，不在網頁裡。圖檔不會離開這台電腦。

## 能做什麼、不能做什麼

**能做**：2.5D 板件。從上面一次裝夾加工的東西：

- 孔：鑽孔、攻牙（依底孔直徑判 M4／M5／M6／M8／M10）、沉孔（同心兩個圓）、大孔（Ø25 以上用平刀螺旋分層銑穿）
- 封閉輪廓：穿透窗口（G41 輪廓分層切穿）、長圓槽（分層清料）
- 全部孔口與輪廓的 C0.5 倒角
- 配刀只從你給的刀具表挑，挑不到的刀標「需新增」，不會自己發明一把刀

**不能做**：多面加工、曲面、口袋裡有島、側銑斜面、車床。圖上的文字（深度、公差、備註）它讀不到，只看幾何：孔徑從圓的半徑判、比例從板外形的長寬算。所以深度這類資訊要你在報告裡核對。

## 需求

- Python 3.10 以上，加 [ezdwg](https://pypi.org/project/ezdwg/)（MIT 授權，讀 DWG 用）：

  ```bash
  pip install ezdwg
  ```

- 畫刀具路徑圖要 matplotlib（可不裝）：`pip install matplotlib`
- 用預演台驗證要 Node 22 以上（和 nc-preview 一樣，不用 npm install）

## 用法

在 repo 根目錄：

```bash
python tools/dwg2nc/dwg2nc.py 圖.dwg --plate 900x330x15 --onum 2001 --name PART-A --tools 刀具表.csv
```

| 參數 | 說明 |
|---|---|
| `圖.dwg` | 客戶的 DWG。AutoCAD 2000（AC1015）到 2018 都試過能讀 |
| `--plate 寬x高x厚` | 板的實際尺寸（mm），**必填**。工具用它算圖面比例、找零件視圖 |
| `--tools CSV` | 現有刀具表，格式就是預演台「匯出 CSV」的那份。不給的話所有刀都標需新增 |
| `--onum` | O 號，預設 2001 |
| `--name` | 程式名稱註解，預設用檔名 |
| `--origin LB\|RB\|LT\|RT` | 工件原點放板的哪個角，預設左下。Z0 一律在上表面 |
| `--region x0,y0,x1,y1` | 零件視圖在紙面上的範圍。一張圖有好幾個視圖時通常不用給，它會找長寬比符合、認得出孔最多的那個矩形；找錯了再用這個指定 |
| `--subfaces skip\|thru` | 窗口內被線分割出的小區域（圖上常是階梯或另一個深度）：預設不切、列為待確認；確認是穿透就 `thru` |
| `--skin 0.3` | 窗口最後一刀留皮，免得切穿時中間那塊料掉下來 |
| `--out 資料夾` | 輸出位置，預設是 DWG 旁邊的 `out/` |

輸出四個檔，以 O 號命名：

| 檔案 | 內容 |
|---|---|
| `O2001.nc` | NC 程式。寫法照現場常見的 Fanuc 習慣：G98 R2 固定循環、G83 啄鑽、M29 剛性攻牙、G41 直線進退刀、G05.1 |
| `O2001_tools.csv` | 刀具表，備註欄寫「現有（哪支程式的 T 幾）」或「需新增」 |
| `O2001.stock.json` | 素材，拖進預演台就套用 |
| `O2001_report.md` | 加工內容、刀具、所有假設與待確認事項。**上機前先讀這份** |

## 拿到預演台看

1. 把 `O2001.nc` 拖進預演台。
2. 再拖 `O2001_tools.csv`（刀具表匯入）。
3. 再拖 `O2001.stock.json`（素材）。

或用命令列跑一樣的分析、把刀具路徑畫成圖：

```bash
node tools/dwg2nc/verify_nc.mjs 圖所在資料夾/out/O2001      # 預演台的 37 條檢查 + 模擬
python tools/dwg2nc/plot_paths.py 圖所在資料夾/out/O2001    # 產生 O2001_paths.png
```

## 它做了哪些假設

報告裡會逐條列出，重點是：

- **切削條件是鋁的保守值。** 鑽頭 Vc 約 25 m/min，Ø8 平刀 S2800 F300 每層 3 mm。切別的材料自己改。
- **通孔和窗口切到板下 0.3 mm**，要墊板。窗口切穿後中間那塊料會掉，要固定住或用 `--skin` 留皮。
- **沉孔深度**看不到文字，用常見規格：Ø10.5 深 6、Ø12 深 8。
- **倒角**用 Ø10 的 90° V 刀：小孔下插，大孔、槽、窗口刀尖在 Z-2 走輪廓，輪廓補正用 D21=1.5（不是刀半徑，刀具表裡有寫）。
- **公差孔**（例如 Ø35 +0.025）銑小 0.6 留給搪孔刀。

## 它怎麼認圖

1. 找板外形：一條水平線接一條垂直線、長寬比和 `--plate` 一致的矩形。同一塊板畫在好幾張圖紙時，挑疊了最少雜物的那一張。
2. 比例 = 板寬 ÷ 矩形寬。原點放你指定的角。
3. 孔：矩形內的每個圓，直徑對到最近的標稱值（3.3、4.2、5、5.3、5.5、6.3、6.5、10.5、12、25…），同心的合併成沉孔。
4. 輪廓：把直線、圓弧、聚合線串起來，先反覆剪掉懸空的線（尺寸線、延伸線、引線、炸開的文字），再用面追蹤找封閉區域。內角半徑比刀半徑小的輪廓會換小刀或列為待確認。

認錯了會反映在報告的孔位統計和輪廓清單上，先對這兩段再看程式。

## 給維護的人

- 三個檔案彼此獨立：`dwg2nc.py` 只靠 ezdwg；`verify_nc.mjs` 靠 `nc-preview/test/load.mjs` 載入核心模組；`plot_paths.py` 只讀 `verify_nc.mjs` 倒出的 `_paths.json`。
- 別把客戶的 DWG 或產出的程式 commit 進來。`.gitignore` 已擋 `*.dwg` 和 `tools/dwg2nc/out/`，放別處請自己注意。
- 想加新的孔徑或牙規格，改 `NOM`、`TAP`、`CBORE_DEPTH` 三個表。
